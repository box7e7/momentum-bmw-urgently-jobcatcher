# BMW Authentication Page Automation

This project uses Puppeteer to automate opening the BMW authentication page.

## Requirements
- Node.js
- npm

## Installation
1. Clone this repository
2. Run `npm install` to install dependencies

## Usage
Run the script with:
```bash
node index.js
```

This will:
1. Launch a new browser window
2. Navigate to the BMW authentication page
3. Keep the browser window open for interaction
